ffmpeg

FFmpeg是一款功能强大的开源多媒体处理工具，能够处理视频、音频等文件的转换、编辑、流媒体处理等几乎所有的操作。由于其命令行操作方式，初次接触可能会觉得复杂，但只要掌握其核心逻辑，就能高效完成各种任务。

下面这个表格汇总了FFmpeg的一些典型应用场景和对应的命令结构，方便你快速了解其能力范围。

应用场景 示例命令 关键参数说明
格式转换 ffmpeg -i input.avi output.mp4 -i 指定输入文件
提取音频 ffmpeg -i video.mp4 -vn -acodec copy audio.aac -vn 忽略视频流，-acodec copy 直接复制音频流不重编码
提取视频 ffmpeg -i input.mp4 -vcodec copy -an output_video.mp4 -an 忽略音频流
视频剪辑 ffmpeg -ss 00:00:10 -to 00:00:30 -i input.mp4 -c copy clip.mp4 -ss 开始时间，-to 结束时间，-c copy 使用流复制模式（快速）
调整分辨率 ffmpeg -i input.mp4 -vf scale=640:480 output.mp4 -vf 引入视频滤镜，scale 用于调整尺寸
添加水印 ffmpeg -i video.mp4 -i logo.png -filter_complex "overlay=10:10" output.mp4 -filter_complex 处理复杂滤镜链，overlay 将图片叠加到视频上
修改码率 ffmpeg -i input.mp4 -b:v 1000k -b:a 128k output.mp4 -b:v 视频码率，-b:a 音频码率
截图/抽帧 ffmpeg -i input.mp4 -ss 00:01:00 -vframes 1 screenshot.jpg -vframes 1 指定只输出一帧视频帧

💻 第一步：安装与验证

  1. 安装FFmpeg

    • Windows: 访问 https://ffmpeg.org/ 下载预编译的二进制文件，解压后将 bin 文件夹的路径添加到系统的环境变量 Path 中 。
    • macOS: 使用包管理器Homebrew，在终端中运行 brew install ffmpeg 。
    • Linux (如Ubuntu): 使用系统包管理器，例如 sudo apt update && sudo apt install ffmpeg 。

  2. 验证安装 打开终端或命令提示符，输入以下命令，如果显示版本信息则说明安装成功。 bash ffmpeg -version

🎯 第二步：掌握核心命令结构

FFmpeg的命令行遵循一个基本模式，理解它就能举一反三：

ffmpeg [全局参数] -i [输入文件] [输出选项] [输出文件]
  • 全局参数：影响整个FFmpeg进程的行为，例如 -y 表示直接覆盖已存在的输出文件。
  • -i 参数：这是最重要的参数，用于指定输入的源文件。
  • 输出选项：非常灵活，用于指定对输入文件进行何种处理，比如转码、滤镜、剪切等。
  • 输出文件：指定处理后的文件路径和文件名。FFmpeg会根据文件扩展名自动判断输出格式。

🛠️ 第三步：常用操作详解

1. 获取媒体文件信息

在处理文件前，可以先查看其详细信息，如编码格式、分辨率、时长、码率等。

ffmpeg -i input.mp4

或者使用 ffprobe（FFmpeg套件的一部分）获取更简洁或更详细的信息 。

ffprobe input.mp4

2. 转换格式与编码

这是最常用的功能。下面的例子将视频转换为H.264编码的MP4文件，音频转换为AAC编码。

ffmpeg -i input.avi -c:v libx264 -c:a aac output.mp4
  • -c:v libx264：指定视频编码器为 libx264（一种常用的H.264编码器）。
  • -c:a aac：指定音频编码器为 AAC。

3. 音视频流分离

  • 从视频中提取音频（不重新编码，速度快）： bash ffmpeg -i video.mp4 -vn -acodec copy audio.aac
  • 从视频中移除音频，只保留视频： bash ffmpeg -i input.mp4 -vcodec copy -an output_video.mp4

4. 视频剪辑与裁剪

  • 按时间剪辑：从第10秒开始，截取20秒长的视频（使用流复制，速度极快）。 bash ffmpeg -ss 00:00:10 -t 00:00:20 -i input.mp4 -c copy clip.mp4 注意：将 -ss 参数放在 -i 之前可以实现更快速的定位。
  • 按尺寸裁剪：裁剪视频画面的一部分，例如从坐标(100,50)开始，裁出一个宽640像素、高480像素的区域。 bash ffmpeg -i input.mp4 -vf "crop=640:480:100:50" output.mp4

5. 使用滤镜处理音视频

FFmpeg的滤镜系统（-vf 用于视频滤镜，-af 用于音频滤镜）非常强大。 * 调整分辨率：将视频缩放至1280x720像素。 bash ffmpeg -i input.mp4 -vf scale=1280:720 output.mp4 * 添加文字水印：在视频左上角(10,10)的位置添加白色文字。 bash ffmpeg -i input.mp4 -vf "drawtext=text='Hello World':x=10:y=10:fontsize=24:fontcolor=white" output.mp4 * 调整音量：将音频音量调整为原来的0.5倍。 bash ffmpeg -i input.mp3 -af "volume=0.5" output.mp3

⚡ 第四步：进阶技巧与性能优化

  1. 硬件加速：如果你的显卡支持（如NVIDIA GPU），可以利用硬件编码器大幅提升处理速度。 bash ffmpeg -hwaccel cuda -i input.mp4 -c:v h264_nvenc output.mp4

  2. 控制输出质量与体积：

    • CRF（恒定速率因子）：用于H.264/H.265编码，在保证质量的前提下控制体积。CRF值越小，质量越高，文件越大。通常18-28是常用范围。 bash ffmpeg -i input.mp4 -c:v libx264 -crf 23 -preset slow output.mp4
    • Preset：控制编码速度与压缩效率。从快到慢有 ultrafast, superfast, veryfast, faster, fast, medium, slow, slower, veryslow。越慢压缩效率越高，生成的文件越小。

  3. 批量处理：可以结合Shell脚本（Linux/macOS）或批处理脚本（Windows）来批量处理文件。例如，将当前目录下所有 .avi 文件转为 .mp4： Linux/macOS: bash for f in *.avi; do ffmpeg -i "$f" "${f%.avi}.mp4"; done

💡 实用建议

  • 循序渐进：先从简单的格式转换、信息查看开始，逐步尝试滤镜、流映射等复杂功能。
  • 查阅文档：遇到不熟悉的参数，可以使用 ffmpeg -h 查看帮助，或访问 https://ffmpeg.org/。
  • 先测试再处理：对重要文件进行操作前，可以先在一小段视频或备份文件上测试命令效果。
