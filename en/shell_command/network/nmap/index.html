nmap

Network Mapper

Network exploration tool and security / port scanner

# 扫描某主机的某个端口段
nmap xxx.xxx.xxx.xxx -p 8000-8100 -sV

# TCP SYN 扫描（半开放扫描），比全连接扫描更隐蔽快速。
nmap xxx.xxx.xxx.xxx -p 8000-8100 -sS

# 禁用主机发现，直接扫描指定端口。
nmap xxx.xxx.xxx.xxx -p 8000-8100 -Pn

# 详细输出，显示更多扫描过程信息。
nmap xxx.xxx.xxx.xxx -p 8000-8100 -v

# 将标准结果输出到文本文件。
nmap xxx.xxx.xxx.xxx -p 8000-8100 -oN result.txt

结果字段

​​PORT​​: 端口号及协议（如 8000/tcp）。
​​STATE​​: 端口状态。常见状态有：
    open- 端口开放，有服务正在监听
    closed- 端口关闭，没有服务监听
    filtered- 端口可能被防火墙过滤，无法确定状态
​​SERVICE​​: Nmap根据端口号推测的服务名称。
​​VERSION​​ (在使用了 -sV时显示): 探测到的服务软件及其版本信息
