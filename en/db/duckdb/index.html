duckdb

主页 文档

简介

DuckDB 是一个开源的嵌入式分析数据库，专为高性能的OLAP（联机分析处理）场景设计，尤其适合与 Python 生态（如 Pandas）结合使用。

典型应用场景

  1. 本地数据探索
  2. 替代 SQLite 处理复杂分析需求，无需搭建分布式集群，个人感觉比sqlite3和jq更易用。

  3. 文件处理：https://duckdb.org/docs/stable/guides/file_formats/overview

    ```bash

    通过后缀加载csv/xlsx/json/parquet文件

    duckdb -c "select * from 'xxx.csv' limit 3" duckdb -c "select * from 'xxx.json' limit 3" duckdb -c "select * from 'xxx.xlsx' limit 3" duckdb -c "select * from 'xxx.parquet' limit 3"

    通过明确方法加载csv/xlsx/json/parquet文件

    duckdb -c "select * from read_csv('xxx.csv')"

    读取无表头、分号分隔的 CSV，并手动定义列

    duckdb -c "SELECT * FROM read_csv('data.csv', delim=';', header=false, columns={'id': 'INTEGER', 'name': 'VARCHAR'})" duckdb -c "select * from read_json('xxx.json')" duckdb -c "select * from read_xlsx('xxx.xlsx')" duckdb -c "select * from read_parquet('xxx.parquet')"

    读取文本（read_text）或二进制文件(read_blob)

    duckdb -c "SELECT size, parse_path(filename), content FROM read_text('test/sql/table_function/files/.txt');" duckdb -c "SELECT size, parse_path(filename), content FROM read_blob('test/sql/table_function/files/.zip');"

    通过通配符批量统计多个文件

    duckdb -c "select count() from '/path/to/many/.json'"

    导出为csv/json文件

    duckdb -c "COPY (SELECT * FROM tbl) TO 'output.csv' (HEADER, DELIMITER ',');" duckdb -c "COPY (SELECT * FROM range(3) tbl(n)) TO 'output.json' (ARRAY);"

    格式化输出(SQL1按每列一行输出，SQL2按json格式输出)

    duckdb -line -c "SQL1" -json -c "SQL2" ```

  4. Python 数据分析

  5. 直接读取 Pandas DataFrame，执行复杂 SQL 分析（如时间序列聚合、用户行为分析）。

  6. 示例代码： ```python import duckdb import pandas as pd

    df = pd.DataFrame({"a": [1, 2, 3], "b": [4, 5, 6]}) conn = duckdb.connect() conn.execute("SELECT a + b FROM df").show() ```

  7. 数据科学工作流

  8. 与 Jupyter Notebook、Databricks 等工具结合，快速验证分析逻辑。

  9. 轻量级 BI 工具后端

  10. 为小型 BI 工具或内部工具提供数据分析支持。

核心特性

  1. 嵌入式架构
  2. 无需独立服务器进程，可直接嵌入到应用程序中（如 Python 脚本、Jupyter Notebook）。

  3. 单文件存储（类似 SQLite），轻量且易于部署。

  4. 向量化执行引擎

  5. 基于列式存储，支持批量数据处理，优化了大规模数据分析性能。

  6. 利用 SIMD 指令和多核并行加速查询（MPP 架构）。

  7. SQL 兼容性

  8. 支持标准 SQL 查询，提供类 Pandas 的 API（如 SELECT、JOIN、窗口函数）。

  9. 可直接操作 Parquet、CSV、JSON 等数据格式。

  10. 与 Python 深度集成

  11. 通过 duckdb Python 库无缝连接 Pandas DataFrame，支持零拷贝数据交互。

  12. 示例：直接在 Jupyter Notebook 中运行 SQL 查询 Pandas 数据。

  13. 高效内存管理

  14. 针对分析型负载优化内存占用，适合资源受限环境。

关键优势

  • 高性能：比传统嵌入式数据库（如 SQLite）快数十倍，尤其适合复杂聚合和多表关联。
  • 易用性：无需复杂配置，适合快速原型开发和小型到中型数据分析任务。
  • 开源免费：采用 Apache 2.0 协议，社区活跃，文档完善。

与其他数据库对比

特性 DuckDB SQLite BigQuery/Redshift
部署方式 嵌入式（单文件） 嵌入式 云服务
适用场景 OLAP 分析 OLTP 事务处理 超大规模分布式分析
性能优化 向量化执行、列式存储 行式存储 MPP、列式存储
生态系统集成 Python/Pandas 原生支持 通用 需通过 API 或 JDBC

局限性

  • 不适合高并发 OLTP：设计目标为单用户分析，不支持多用户事务。
  • 内存限制：处理超大规模数据（TB 级）时需结合外部存储（如 Parquet 文件）。

总结

DuckDB 是面向开发者和小团队的轻量级分析工具，尤其适合以下场景：
✅ Python 数据分析（Pandas 无缝集成）
✅ 嵌入式分析（如桌面应用、移动端）
✅ 快速原型开发（无需复杂运维）

其设计哲学是“让 SQL 更贴近编程语言”，是 Pandas 用户处理复杂查询的理想补充。
